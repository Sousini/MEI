## ⚙️ Como usar

```bash
# Clonar o repositório
git clone https://github.com/Sousini/MEI.git
cd MEI
```

Cada UC ou projeto inclui, sempre que aplicável, as suas próprias instruções de compilação e execução.

## ⚠️ Nota

Este repositório serve fins **académicos e de organização pessoal**. Se és estudante da mesma UC, usa estes materiais apenas como referência e respeita as regras de integridade académica da tua instituição.
